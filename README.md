# CV Maker

Генератор резюме під польський ринок праці: шаблони, дружні до ATS, шаблони з фото, клаузула RODO, живе превʼю A4 та експорт у PDF. Працює повністю в браузері, без сервера, акаунтів і ключів. Дані CV лежать лише в localStorage вашого браузера.

## Вимоги

- Node.js 22 або новіший, npm 10+ (потрібно для Capacitor 8).

## Запуск (Windows, PowerShell)

```powershell
cd cv-maker
npm install
npm run dev
```

Відкрийте http://localhost:5173.

Продакшн-збірка (статичні файли в `dist/`, їх можна віддавати будь-яким статичним хостингом):

```powershell
npm run build
npm run preview     # локальний перегляд зібраного, http://localhost:4173
```

Перевірки:

```powershell
npm run typecheck   # tsc --noEmit
npm test            # 46 тестів: логіка CV, фото, PDF-документ, стан
```

## Android-додаток (Capacitor + Android Studio)

Той самий веб-застосунок загортається в Android WebView. Потрібні Node.js 22+ і Android Studio 2025.2.1 або новіша (JDK встановлюється разом з нею).

```powershell
npm install
npx cap add android        # лише один раз: створює папку android/
npm run android:sync       # збирає веб-версію, копіює її в android/ і додає власний нативний код
npm run android:open       # відкриває проєкт в Android Studio
```

Після кожної зміни коду повторюйте `npm run android:sync`. В Android Studio: підключіть телефон (режим розробника та «Налагодження USB») або створіть емулятор і натисніть Run. Для APK: **Build → Build Bundle(s) / APK(s) → Build APK(s)**, файл буде в `android/app/build/outputs/apk/debug/app-debug.apk`.

### Збереження файлів на телефон

PDF і резервна копія на Android зберігаються прямо в папку «Pobrane» (Downloads) через власну нативну вставку `SaveFilePlugin` (MediaStore, без жодних дозволів, Android 10+). Після збереження з'являється вікно «Zapisano na telefonie» з кнопками «Gotowe» і «Udostępnij» (системне вікно «Поділитися»). На Android 9 і старших, або якщо вставки немає, застосунок відкриває лише вікно «Поділитися», як раніше.

Нативний код лежить у `native/` (шаблони `.tpl`). Скрипт `scripts/install-native.mjs` сам копіює його в `android/`, підставляє `appId` з `capacitor.config.ts`, реєструє вставку в `MainActivity` підставляє назву під іконкою з `appName` і `admob_app_id` з `src/monetization/config.ts` в `strings.xml`, а в `AndroidManifest.xml` додає запис AdMob, якщо його немає. Його можна запускати скільки завгодно разів: `npm run android:native` (окремо) або `npm run android:sync` (разом зі збіркою). Після `npx cap add android` на новій папці `android` досить `npm run android:sync`.

### Резервна копія

На Strona główna внизу є блок «Kopia zapasowa» (також у Ustawienia): «Zapisz kopię do pliku» зберігає всі власні CV (з фото, без зразка) в один файл `cv-maker-kopia-РРРР-ММ-ДД.json`, «Wczytaj kopię z pliku» повертає їх. Повторне завантаження того самого файлу нічого не дублює, а інша версія того ж CV додається як нове CV, нічого не перезаписуючи. Логіка в `src/domain/backup.ts`, збереження файлу в `src/export/backupFile.ts`. На Android файл зберігається в «Pobrane», а з вікна після збереження його можна ще й відправити (Диск, пошта). Файл не зашифрований і містить особисті дані.

### Реклама (Google AdMob)

У додатку Android кнопка «Pobierz PDF» працює так: якщо є «запас» (раніше переглянута, але невикористана реклама) або куплено «без реклами» (покупку додамо пізніше), PDF зберігається одразу. Інакше з'являється вікно «Obejrzyj reklamę»; після перегляду до кінця PDF зберігається автоматично. «Запас» зменшується лише після вдалого збереження, тому помилка не коштує реклами. У веб-версії (браузер) реклами й обмежень немає.

Усі налаштування в `src/monetization/config.ts` (`adsEnabled`, `testAds`, ідентифікатор блоку). Логіка рішення в `src/domain/access.ts` (покрита тестами), показ реклами та згода Google UMP в `src/monetization/ads.ts`.

**Налаштування Android (один раз, для тестової реклами):**

1. `npm install`, потім `npm run android:sync`.
2. У `android/app/src/main/AndroidManifest.xml` усередині `<application ...>` додайте рядок:

```xml
<meta-data android:name="com.google.android.gms.ads.APPLICATION_ID" android:value="@string/admob_app_id" />
```

3. У `android/app/src/main/res/values/strings.xml` усередині `<resources>` додайте рядок (це тестовий ідентифікатор Google):

```xml
<string name="admob_app_id">ca-app-pub-3940256099942544~3347511713</string>
```

4. Run в Android Studio. Мають показуватися тестові оголошення з позначкою «Test Ad».

Ідентифікатори вашого акаунта AdMob уже вписані в `src/monetization/config.ts` (`admobAppId` і `rewardedAdUnitId`), а `npm run android:sync` сам переносить `admobAppId` у `strings.xml`. Поки стоїть `testAds: true`, показуються лише тестові реклами Google. **Перед публікацією в Production** поставте `testAds: false`. Не клікайте по власній справжній рекламі.

### Назва та іконка

Назва додатку: **CV Maker** (`capacitor.config.ts`, `appName`). Вихідні зображення іконки лежать у `assets/` (`icon-only.png`, `icon-foreground.png`, `icon-background.png`, по 1024×1024). Щоб підставити їх в Android: `npm run android:icons`, потім `npm run android:sync`. Назва під іконкою береться з `capacitor.config.ts` (`appName`): `npm run android:sync` сам підставляє її в `android/.../strings.xml` (`app_name`).

Особливості Android-версії:
- PDF зберігається в кеш додатка й відкривається системне вікно «Поділитися» (зберегти на диск, Диск Google, пошта тощо), бо WebView не підтримує завантаження через `<a download>` (`src/export/exportPdf.ts`).
- Дані CV лежать у сховищі додатка й окремі від даних у браузері на тому самому телефоні.
- Перед публікацією в Google Play змініть `appId` у `capacitor.config.ts`: після публікації його змінити не можна. Для Google Play потрібні підписаний `.aab`, політика приватності (в CV є особисті дані й фото) та заповнена форма Data safety.

## Структура

```
index.html, vite.config.ts, tsconfig.json, capacitor.config.ts
src/
  domain/             чиста логіка без React: типи, переклади, клаузула RODO, перевірки якості, кадр фото, PDF-документ
  store/              стан (reducer), збереження в localStorage
  components/         React: Dashboard, Editor, вкладки Treść / Wygląd, Paper (аркуш A4), Preview, PhotoView
  export/             pdfmake (завантаження й скачування), обробка фото в canvas
tests/                node:test, запускаються через tsx
```

Усе, що можна перевірити без браузера, лежить у `domain/` і покрите тестами. React-компоненти тонкі.

## Шаблони та ATS

Дванадцять шаблонів, 6 акцентних кольорів, 3 щільності, мова документа PL/EN:

| Шаблон | Фото | Колонки | Читабельність для ATS (наша оцінка) |
|---|---|---|---|
| Klasyczny | ні | одна | висока |
| Nowoczesny | так, коло в кольоровій шапці | одна | висока |
| Minimalny | ні | одна | висока |
| Executive | так, коло в темній шапці | одна | середня |
| Kreatywny | ні | дві (темна панель + текст) | нижча |
| Techniczny / IT | ні | одна | висока |
| ATS (prosty) | ні | одна, чорно-біла | висока |
| Panel boczny | так, коло в бічній панелі | дві | нижча |
| Elegancki | ні | одна, кремовий фон | середня |
| Wyrazisty | ні | одна, темна шапка | середня |
| Przemysłowy | ні | одна, смуги-заголовки | середня |
| Nordycki | так, коло біля імені | дві (світла панель справа) | нижча |

Оцінка ATS: це наша приблизна оцінка за складністю макета, а не результат перевірки в реальних системах. Реальний парсинг перевірити неможливо, тому в галереї так і написано: «nasza ocena».

Старе збережене CV із шаблоном «portrait» автоматично відкривається як «Nordycki».

Галерея показує для кожного шаблону картку: кому підходить, сильні сторони, обмеження й оцінку читабельності для ATS.

**Головна сторінка.** Приклад CV на ній тільки для перегляду: клік відкриває його як аркуш A4 (без редагування, дублювання й видалення). Власні CV мають кнопки «Edytuj», «Duplikuj», «Usuń».

**Вибір шаблону.** «+ Nowe CV» відкриває галерею: кожен шаблон показано як мініатюру справжнього документа (з прикладом даних) і можна вибрати акцентний колір. Після вибору відкривається порожня форма. Змінити шаблон можна будь-коли кнопкою «Wybór szablonu» у редакторі (мініатюри тоді показують ваші власні дані, текст не змінюється) або у вкладці «Wygląd».

Усі шаблони використовують стандартні заголовки (Podsumowanie zawodowe, Doświadczenie zawodowe, Wykształcenie, Umiejętności, Języki, Zainteresowania). PDF створюється з реальним текстом (pdfmake, Roboto), тому парсери ATS можуть його прочитати.

**Шаблони з бічною панеллю (Kreatywny, Panel boczny, Nordycki) і ATS.** Контакти та частина блоків лежать у бічній панелі поруч з основним текстом. У PDF вміст панелі стоїть лише на першій сторінці. Частина ATS читає таке в неправильному порядку або губить панель. У редакторі шаблон має позначку «2 kolumny», ostrzeżenie та не проходить 8-те правило «Szablon jednokolumnowy». Для порталів з автоматичним читанням CV обирайте одноколонковий шаблон, а Panel залишайте для відправки поштою чи друку.

**Фото.** Додається у вкладці «Treść». Воно необов'язкове: за art. 22¹ KP роботодавець не може його вимагати. Файл зменшується до 640 px і зберігається як JPEG у localStorage. Кадр регулюється жестами прямо на фото: перетягування (миша, палець), щипок двома пальцями та колесо миші. Це працює і у формі, і на фото в превʼю документа (там колесо зі Ctrl, щоб не заважати прокручуванню сторінки). Кнопка «Przywróć ustawienia kadru» повертає стандартний кадр. Кадр у превʼю й у PDF обчислюється однією формулою (`src/domain/photo.ts`) і збігається. Якщо фото видно в документі, клаузула RODO додає «(w tym wizerunku)». У PDF фото вставляється як круглий PNG із прозорістю.

Додаткові дані (adres, data i miejsce urodzenia, prawo jazdy) необов'язкові. Роботодавець може вимагати лише дані з art. 22¹ Kodeksu pracy.

Структура документа: контакти, підсумок, досвід (знизу вгору за датою, є кнопка «Sortuj od najnowszych»), освіта, навички (hard/soft), мови, інтереси, клаузула RODO.

## Клаузула RODO

Текст у `src/domain/docText.ts` (`rodoText`). Є два варіанти: лише поточна рекрутація або також майбутні. Можна вказати посаду. Це шаблонний текст, який відповідає поширеній практиці; перед комерційним запуском його варто показати юристу або IOD.

## Шрифти

Inter та Roboto підключені через `@fontsource` і віддаються з вашого сервера, а не з Google Fonts. Так браузер не надсилає IP користувача стороннім.

## Що перевірено

- 46 тестів проходять: логіка CV, клаузула RODO, нормалізація даних (зокрема фото), reducer, збереження, математика кадру й жестів, PDF-документ для всіх шаблонів.
- Інтерфейс зібрано esbuild і пройдено в Chromium: пульт, редагування з живим превʼю, шаблони, фото та жести (миша, колесо, щипок), RODO, збереження після перезавантаження, світла й темна тема, телефон (390 px).
- Ваші власні PDF з усіх трьох типів (одноколонковий із фото, Panel з фото та без) відкриті й виглядають правильно.

## Що перевірте самі

- Читання PDF справжніми ATS (Pracuj.pl тощо) не перевірялося.
- Клаузулу RODO варто показати юристу перед комерційним використанням.

## Не реалізовано

- Перетягування елементів мишею: зараз є кнопки ↑ ↓ ✕ і додавання.
- Акаунти, база даних, синхронізація між пристроями: версії CV лежать у localStorage браузера (очищення даних сайту їх стирає).
- Експорт у DOCX.
